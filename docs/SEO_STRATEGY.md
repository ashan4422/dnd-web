# SEO Strategy (draft)

The website's main job is search ranking. This file collects the SEO plan; it will grow as work progresses.

## 1. Protect what already ranks
- Before launch, crawl the current Joomla site (dndlanka.com, live since ~2017) and list every indexed URL.
- 301-redirect each old URL to its new equivalent (e.g. `/index.php/products/bearings` → `/products/bearings`).
- Keep the domain **dndlanka.com**.

## 2. Fix NAP consistency (found during research; a quick win)
Name / Address / Phone differ across the web, which weakens local rankings:
- Head office shows as **281 Panchikawatte Rd** (own site, TradeIndia, ikman) *and* **247 Sri Sangaraja Mawatha** (LinkedIn, LankaYP).
- Phone numbers differ: 011 475 8888 / 011 462 1337 / 011 471 8292 / 011 234 7810.
- Founding year shows as 1990 and as 1982.

**Action:** once the MD confirms the correct details, use them on the new site and update LinkedIn, Facebook, LankaYP, Rainbowpages, TradeIndia, mypromo.lk, ikman and ipscasia.

## 3. Local SEO for 5 branches
- One Google Business Profile per branch (Colombo, Kandy, Kurunegala, Negombo, Anuradhapura), each verified and linked to its own branch page.
- Each branch page: unique text, map, hours, phone/WhatsApp, LocalBusiness schema.

## 4. Pages that win searches
| Page type | Example searches it targets |
|---|---|
| Category | "oil seals Sri Lanka", "hydraulic seals Colombo" |
| Brand | "SKF bearings Sri Lanka", "NOK oil seals dealer" |
| Product / part number | "6205 2RS bearing", "TC 35x52x7 oil seal" |
| Industry | "bearings for rice mills", "seals for excavators" |
| Branch | "bearing shop Kandy", "oil seals Kurunegala" |
| Guides (blog) | "how to measure an oil seal", "bearing number meaning" |

Part-number pages are usually the biggest long-tail opportunity for parts distributors, so the depth of the catalogue (R4) matters.
Example searches are placeholders; we'll check them with Google Search Console and keyword tools.

## 5. Technical SEO
Server-rendered pages, sitemap, robots.txt, canonical tags, structured data (Organization, LocalBusiness, Product, BreadcrumbList, FAQ), fast Core Web Vitals, optimised images, hreflang when languages are added.

## 6. Authority
- Get listed on manufacturers' distributor-locator pages where D&D is an authorized distributor (NOK/Corteco etc., once confirmed).
- Industry directories, chamber of commerce, local news/PR.

## 7. Measure
Google Search Console + Google Analytics 4 (or a privacy-friendly alternative), set up before launch; monthly ranking report.
